# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-13

### Added

- Standalone Hermes user plugin for evidence-based local video rough cuts.
- Media inspection, proxy generation, storyboard extraction, transcription, structured edit planning, timeline validation, preview rendering, and JSON/EDL export.
- Path-containment, no-shell invocation, approval-hook, and isolated integration-test coverage.
